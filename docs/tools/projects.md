# Проекты

> Инструмент `tool-projects`, маршрут `/tools/projects`, коллекция `projectsItems` (таблица `projects_items`). Заведён генератором 22.11.2026.

## Зачем

Портфель инвестпроектов: сколько вложено, какая доходность, на каком этапе каждый проект.
Для руководителей и админа (решение владельца, 22.11.2026).

## Данные

| Поле | Колонка | Тип | Правило |
| :--- | :--- | :--- | :--- |
| `title` | `title` | text | обязательно, ≤ 200 символов |
| `amount` | `amount` | float | объём инвестиций, ₸, ≥ 0, округление до копеек |
| `yieldPct` | `yield_pct` | float | % годовых, от −100 до 1000; убыток — отрицательное |
| `startDate` | `start_date` | date | `YYYY-MM-DD`, необязательно |
| `status` | `status` | text | `planned` / `active` / `paused` / `closed`, по умолчанию `planned` |

Генератор добавил дубль названия `name` — убран до первого пуша миграции 004 (22.11.2026).

## Устройство

- Доступ: руководители и админ (`read/write: 'manager'` в `collections.js`).
- Сервисный слой `app/src/api/modules/projects.ts`: вся валидация (`clean`), подписи статусов
  `PROJECT_STATUSES`, сводка `summary()` — чистая функция по уже отфильтрованному списку.
- Экран `app/src/pages/tools/projects/ProjectsPage.tsx`:
  - KPI по текущему фильтру: объём, **средневзвешенная по объёму** доходность, число проектов;
  - фильтр по статусу — `SegmentedControl` glisse (выбранный — золото);
  - список: таблица от `lg`, карточки на телефоне; правка и создание — одна модалка, удаление — с подтверждением.
- Палитра: доходность — `Delta` (positive/negative + знак и стрелка, это финрезультат к нулю);
  статусы — `Badge` с иконкой: планируется/закрыт — neutral, в работе — info, приостановлен — warning.
  Зелёный/красный для статусов не используются.
