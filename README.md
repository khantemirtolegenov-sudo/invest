# {{PROJECT_NAME}}

Шаблон внутреннего портала компании — выжимка проверенных решений портала ColliersHUB
(4 месяца, ~40 инструментов, 96 миграций). Берёте шаблон — получаете за день фундамент,
на который там ушёл месяц: вход и роли, данные с правами на сервере, живое обновление,
уведомления, генератор инструментов, проверки до выкладки.

**Как работать с ним по шагам — [PLAYBOOK.md](PLAYBOOK.md). Правила для Claude — [CLAUDE.md](CLAUDE.md).**

## Быстрый старт

Нужны Node.js 20+ и PostgreSQL 14+.

```bash
npm run setup          # мастер: название, модули, администратор, первые инструменты
npm run install:all    # зависимости
npm run db:seed        # создать администратора (базу из DATABASE_URL создайте заранее)
npm run dev            # http://localhost:5184
```

Работаете с Claude Code — просто откройте папку и скажите «начинаем»: он сам задаст
вопросы мастера (раздел «Первый запуск» в CLAUDE.md).

## Что внутри

| Часть | Что даёт |
| :--- | :--- |
| Вход и пользователи | JWT, роли employee / manager / admin, временный пароль и смена при входе, экран «Пользователи», гранты к инструментам |
| Данные | снапшот + синк: сервисный слой работает с кэшем синхронно, правки уходят пакетом; ящик неотправленного переживает F5; живое обновление вкладок |
| Права | дважды: интерфейс (UX) и сервер на каждую запись; сторож `check:acl` в сборке; журнал отказов `sync_rejections` |
| Генератор | `npm run new-tool` — инструмент со своими данными за минуту: тип, права, таблица, миграция, карточка, экран, маршрут, docs |
| Модули (по выбору) | регистрация с подтверждением, Telegram-уведомления (outbox), загрузка файлов, Docker, GitHub Actions |
| Для Claude | CLAUDE.md с правилами, агенты `verifier` / `acl-guard` / `docs-keeper`, скилы |

## Структура

```
app/                 фронтенд (React + TS + Vite + Tailwind)
  src/api/           кэш данных (db.ts), сервисный слой (modules/*), HTTP
  src/pages/         экраны; инструменты — pages/tools/<id>/
  src/components/ui  кнопки, поля, модалка, состояния
backend/             Express + PostgreSQL
  migrations/        схема базы (append-only)
  src/db/            права (collections.js), таблицы (tables/), синк (store.js)
scripts/             setup, new-tool, check-acl
docs/tools/          документ на каждый инструмент
```

## Выкладка (модуль docker)

```bash
cp .env.docker.example .env      # заполнить пароль базы и JWT_SECRET
docker compose up -d --build     # портал на :8080, миграции применяются сами
docker compose exec app node backend/scripts/seed.js   # первый администратор (SEED_ADMIN_* в окружении)
```
