# Новый инструмент

1. **Бриф** (если нет в просьбе): какие данные (поля и типы), кто видит и правит (admin / manager / all,
   особые правила — «только своё», «только руководитель отдела»), какие действия кроме CRUD, кому уведомления.
2. **Генератор:**
   ```bash
   npm run new-tool -- --id deals --name "Сделки" --fields "title:text,amount:float,dueDate:date,done:bool" --access admin --icon handshake
   ```
   Вписывает тип, Database, права клиента и сервера, таблицу + миграцию + карточку витрины,
   адаптер, модуль `app/src/api/modules/<id>.ts`, экран, маршрут, `docs/tools/<id>.md`. `--dry` — план без записи.
3. **Предметная логика** — в модуле (методы: delay → проверки → mutate → копия) и на экране
   (три состояния, только токены и компоненты `ui/`). Уведомления — `notify()`.
4. **Особые права** (владелец записи, отдел) — в `checkWrite` (`backend/src/db/collections.js`) И в модуле.
   Проверить запросом: запрещённое → 403.
5. `npm run typecheck`, живой прогон (skill verify), `docs/tools/<id>.md` — зачем, устройство, что проверено.
6. Коммит `feat(<id>): …` в фиче-ветке. Пуш — только по команде владельца.
